# NAVER 지도 스타일 색 정리표 — 다크 · 라이트 (2026-11-28)

Style Editor 에서 손으로 넣을 값을 편집기 메뉴 순서대로 정리했다. 발행한 뒤 My Style ID 를 알려 주면 앱의 임시 색 필터(D-057)를 빼고 화면에서 맞춘다.

- **확인한 것**: 편집기의 메뉴·용어(아래 1장)는 NAVER Cloud 공식 가이드 4쪽에서 확인했다.
- **확인하지 못한 것**: 대분류 안의 세부 항목 이름 전체. 가이드에 글로는 없고 화면에만 있다. 이 문서의 세부 항목 이름 중 **굵게** 표시한 것만 우리 기록(`DESIGN.md` §19.4)에 남아 있는 실제 이름이고, 나머지는 "이런 항목"이라는 설명이다 — 편집기에서 이름이 다르면 보이는 이름을 알려 주면 맞춰 준다.
- **색 값**: 앱 화면 색에 맞춰 고른 값이다. 지도에 얹어 본 적은 없어 발행 뒤 한두 번 조정이 필요할 수 있다.

## 1. 편집기 용어 (공식 가이드 기준)

| 용어 | 뜻 |
| --- | --- |
| My Style | 내가 만든 지도 스타일 하나. 목록에 최대 10개, 이름 40자 |
| Feature | 대분류 10개: **심볼 · 경계 · 시설 · 건물 · 도로 · 수계 · 단지 · 녹지 · 등고 · 육지** |
| Mediator | 대분류 안의 세부 항목(실제로 색을 바꾸는 단위). 심볼 107 · 시설 143 · 단지 29 · 도로 18 · 건물 9 · 녹지 3 · 경계·수계·등고·육지 각 1 |
| 색상 스타일링 | 왼쪽 메뉴. 항목의 **메인 색상**과 **테두리선 색상(halo)** 을 바꾼다 |
| 글자 스타일링 | 왼쪽 메뉴. **폰트 종류 · 폰트 크기 · 아이콘 크기** |
| 기타 | **크기 · 투명도 · 가시화 ON/OFF** |
| 빠른 스타일링 | 왼쪽 메뉴. 여러 항목을 한 번에 |
| 스타일링 히스토리 | 오른쪽. 편집 내역과 **되돌리기** |
| [Save] / [Publish] | 위쪽 버튼. 저장 / 발행 |

| 대분류 | 색상 | 테두리선(halo) | 글자 | 가시화 | 투명도 | 크기 |
| --- | --- | --- | --- | --- | --- | --- |
| 심볼(지명·역·POI 글자와 아이콘) | 일부 | 일부 | 가능 | 가능 | 불가 | 불가 |
| 경계 | 가능 | – | – | 가능 | 가능 | 가능 |
| 수계 | 가능 | – | – | 가능 | 불가 | 불가 |

## 2. 순서

1. 콘솔 → Maps → **[Style Editor]**.
2. **다크**: My Style 목록에서 기존 다크 스타일의 ☰ → **복제** → "스타일 복제하기" 창에서 **[복제]**. 복제본을 연다. (끈 항목·지명 굵기 설정이 그대로 따라온다.)
3. **라이트**: "지도 생성"에서 라이트 테마 **[+Create]** 로 새로 만든다.
4. 왼쪽 **색상 스타일링**에서 3·4장 표대로 넣는다. 항목은 검색으로 찾는다(예: "아파트", "지하철").
5. **[Save]** → **[Publish]** → "스타일 발행하기" → **[발행하기]** → "스타일 적용하기" 창에서 **My Style ID** 확인. (나중에는 목록 ☰ → **My Style ID 확인**.)
6. ID 를 `frontend/.env` 에 넣는다 — 다크 `VITE_NAVER_MAP_STYLE_ID`, 라이트 `VITE_NAVER_MAP_LIGHT_STYLE_ID`.

기존 다크 스타일을 직접 고쳐 발행하면 운영 지도가 바로 바뀐다. 복제본으로 하면 배포 전까지 운영은 그대로다.

## 5. 끄고 켜는 것 (가시화)

지금 다크 스타일과 같게 둔다. 라이트를 새로 만들 때는 아래를 직접 꺼야 한다.

| 항목 | 설정 | 이유 |
| --- | --- | --- |
| **POI/일반POI통합** (음식점 등) | OFF | 앱의 점포 점과 헷갈린다 |
| **POI/쇼핑편의_CI** (브랜드 로고) | OFF | 같은 이유 |
| 은행(**은행_CI**) · 지하철역 · 출구 번호 · 건물/아파트 이름 · 공원 · **POI_Landmark** | ON | 위치를 알아보는 기준점 |
| 경계 · 등고 · 보행로 | OFF | 3장 |

다크 스타일의 항목 이름은 `다크모드/POI/…` 처럼 앞에 테마가 붙어 있었다. 라이트는 `라이트모드/…` 일 것으로 보이지만 확인하지 못했다.

## 6. 색을 고른 기준

- 앱 화면 색: 다크 바탕 `#07080A` · 패널 `#0E1013`, 라이트 바탕 `#F4F6F8` · 패널 `#FFFFFF`. 지도 육지는 패널과 살짝 다르게 해 패널이 떠 보이게 했다.
- 지도는 배경이다. 앱이 쓰는 강조색(파랑·청록·보라·로즈) 계열은 지도에 쓰지 않는다 — 전부 무채색, 녹지·수계만 아주 옅은 색 기운.
- 앱이 지도 위에 그리는 것(핀·반경 원·점포 점·업종 지도)이 잘 보이려면 바탕이 조용해야 한다.
