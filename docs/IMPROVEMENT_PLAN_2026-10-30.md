## 4. R1 — 대시보드 리디자인 (v0.1.0)

### 4.1 화면 구조 (`DESIGN.md` §20 신설 예정)
- **첫 화면**: 지도는 그대로 배경이되, 중앙에 큰 입력 카드(위치 방법 전환 + 업종 선택창 + 반경) 하나. 아래에 "최근/보관함" 칩. 코치마크는 첫 방문 1회, 다시 보기는 `?` 버튼(D7).
- **결과 화면(데스크톱)**: 결과가 나오면 **결과 영역이 전폭**이 되고 지도는 오른쪽 위 작은 카드(약 320×200)로 접힌다. 카드를 누르면 지도가 커지고(위치 바꾸기·점포 레이어·반경 원은 이때), 다시 접으면 결과로 돌아온다. 조건 바는 상단 고정.
- **결과 화면(모바일)**: 결과 전체 화면, 지도는 상단 띠(썸네일)로. 첫 스크롤 안에 점수 카드 + 다섯 관점(B3).
- **카드 순서**(팀 시안 규칙 1 + 사용자 요청): 위치·업종·반경 → ① 종합 점수 카드(큰 숫자 + 등급 + 한 줄 결론 + 규제 배너) → ② 다섯 관점(거미줄 그래프 + 점수순 정렬 막대) → ③ 시간대·인구 카드 → ④ 이 자리 업종 순위 카드 → ⑤ (R2) AI 요약 카드 → ⑥ (R3) 지원사업 카드 → 탭(상세 근거·주변 점포·현장 확인·반경 비교) → 접힌 "데이터 한계 N개" → 맨 아래 면책 한 줄.
- **비교 화면**: A·B 두 거미줄을 한 그래프에 겹치고(채운 면/빈 면 + A·B 글자), 관점별 더 높은 쪽 굵게(D3), 하단 버튼은 "A 결과"·"B 결과"(D2).
- **글자**: 본문 15→16px, 근거 12→13px, 자료 단위 11→12px, 점수 숫자 유지(52px). 한 관점 행은 첫 화면에서 숫자·막대·등급만(36px), 누르면 근거 펼침.
- **색**: 블루안 다크 유지 + 라이트. 등급 색 4개를 카드 테두리·막대·배지에 쓴다. 장식용 그라데이션은 종합 점수 카드 배경 한 곳만.

- 개인정보: 프로필·질문 로그에 좌표·IP·식별자 없음, 화면 고지. 외부 전송은 요청 때만.
- 검증은 Definition of Done대로(변경별 → 후보 확정 시 전체 check `--jobs 5` + E2E 1회), 패치노트 D-031(모든 커밋 `Patch-Note: vX.Y.Z`).
- 보고서 7장 "바꾸지 말 것"(근거 투명성·현장 확인·비교 점 그래프·주변 점포·속도)은 리디자인에서 유지한다.
