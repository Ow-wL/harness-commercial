- 출처: [github.com/vuski/admdongkor](https://github.com/vuski/admdongkor) (원천 통계청 SGIS, 공공누리 1유형 / 가공본 CC BY 4.0). 다운로드 URL·sha256은 매니페스트. 다운로드 2026-10-05.
- 재생성: 원본을 `data/geo/raw/`에 받고 `python scripts/build_geo.py` → 매니페스트와 같으면 "재현됨". 매니페스트는 `--manifest`로 최초 1회만 생성(덮어쓰기 거부).
- 변환: 인천(`sido=28`)만 추출. 2026 경계의 `adm_cd2[:8]`이 panel `행정동코드`와 158/158 일치. crosswalk는 2024↔2026 polygon 면적 겹침으로 기계적으로 판정(겹침 ≥ 0.995만 같은 영역, 0.001 미만은 경계선 공유로 무시). 추정 매핑 없음. 통합·경계 변경·이름 변경이 나오면 스크립트가 오류로 멈춘다.
- 결과: 1:1 154개(코드만 변경), 분동 2건 = 중구 운서동 → 영종구 운서1동·운서2동, 서구 아라동 → 검단구 아라1동·아라2동. 158개 polygon은 유효하고 서로 겹치지 않는다(최대 겹침 비율 ~1e-14).
- 이름 표기: 6개 동(`화수1.화평동`, `송현1.2동`, `송림3.5동`, `숭의1.3동`, `용현1.4동`, `도화2.3동`)은 경계 원문이 `·`, panel이 `.`. 조인은 항상 `행정동코드`로 한다.
- 점포 라벨과 polygon 판정의 의미 차이: 상가 데이터의 `행정동코드`는 원천(소진공)이 붙인 라벨이고, resolver는 좌표가 들어 있는 경계 polygon을 본다. 전수 비교 일치율 96.6%이며, 불일치는 대부분 경계 근접(중앙값 30m)이고 남동구 구월1동/3동 구역 하나는 구조적으로 다르다 (D-010).
- 한계: SGIS 공식 배포 파일이 아니라 2차 가공본이다(공식 shp는 로그인·자료신청 필요). 경계 기준일(2026-07-01)과 상가 데이터 기준일(2026-06-30)이 하루 다르다. 상가 점포 라벨과의 일치율 검증(TASKS 1-5)은 아직 하지 않았다. 행정동 경계는 해안·섬 지역에서 바다를 일부 포함할 수 있다.

## 데이터 갱신 (향후)
데이터를 새 시점으로 바꾸면 점수가 바뀐다 = golden이 깨진다. 이는 정상이며, 새 데이터 버전 + 새 golden 버전으로 다룬다 (`docs/DECISIONS.md` D-006). v0.3 데이터와 golden은 보존한다.
