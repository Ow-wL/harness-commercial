## 포함하지 않은 것
- `08_원본_인허가/` (68MB): 안정성 패널을 원본부터 재생성할 때만 쓰는 ETL 입력. 웹 런타임 불필요. 원본 폴더에 그대로 둔다.
- ETL 중간 산출물(`역_인천권.csv`, `유인시설_인천.csv`, `패널_입지성.csv`, `패널_경쟁성.csv` 등): v0.3 원본에도 없고 `run_all.py`가 읽지 않는다. 런타임에 메모리에서 계산한다.
- 07의 8개 파일은 모두 `run_all.py`가 읽으므로 제외한 파일은 없다.

## 데이터 갱신 (향후)
데이터를 새 시점으로 바꾸면 점수가 바뀐다 = golden이 깨진다. 이는 정상이며, 새 데이터 버전 + 새 golden 버전으로 다룬다 (`docs/DECISIONS.md` D-006). v0.3 데이터와 golden은 보존한다.
