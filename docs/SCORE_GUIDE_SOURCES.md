## 1. 원칙

1. 이 결과의 점수·가중치·충족률·업종 정의(타겟 연령, 유인시설)는 정적 문장에 쓰지 않는다. 화면이 API 응답(`종합.기본_가중치`·`적용_가중치`·`데이터_충족률`, `지표[].raw.타겟_정의`·`유인시설_기준`, `meta.업종`·`업종그룹`)으로 채운다. 테스트가 정적 문장에 `%` 수치가 없는지 검사한다.
2. 관점·종합 점수를 순위·"상위 N%"로 설명하지 않는다 (감사 3장).
3. 실태조사 수치(70.9%, 61.0%, 39.9% 등)는 문장에 넣지 않는다. 원본 근거조사 스스로 "언론 보도 요약에서 확인, 원문 재확인 필요"라고 적었기 때문이다(`근거조사_v2.md` 5장 한계). 도입 배경은 "실태조사에서 반복해서 꼽힌 어려움" 수준으로만 쓴다.
4. 고정 규칙값(병목 기준 25점, 관점 산출 기준 50%, 신뢰도 강등 80%·50%, 비교 대상 수 11·158, 거리 감쇠 400m·300m)은 엔진 코드 상수에서 왔다. 엔진 버전이 바뀌면 다시 확인한다.

#### 2-1. 안정성 ETL 근거 (2차-B 보완, 2026-10-11)

[ETL] = `sources/team_v0.3/04_엔진코드/engine/etl_stability.py`, `etl_stability_food.py`. **읽기만 했고 실행하지 않았다.**

**(a) 원본 코드로 확인한 규칙**
- 종료 판정: 영업상태명이 `영업/정상`·`휴업`이 아니면 종료 (`etl_stability.py:36` `ALIVE`, `:57`). 휴업은 영업 중으로 본다.
- 종료일: `폐업일자`, 없으면 `인허가취소일자`로 보완 (`:58-60`). 음식점 파일에는 `인허가취소일자` 열이 없어 빈 값으로 채우므로(`etl_stability_food.py:56-57`) 음식 업종은 폐업일자만 쓴다.
- **종료일 없는 종료 기록:** `survival`은 "종료이면서 생존일수가 있고 N년 이하"만 폐업으로 센다(`:83-85`). 종료일이 없으면 생존일수가 없어 폐업으로 세지 않지만 분모(코호트)에는 남으므로 **생존으로 집계된다 → 생존율 과대평가 가능**. 코드 주석의 "생존율 분자에서 제외"(`:67`)는 "폐업 수(분자)에서 빠진다"는 뜻이다.
- 같은 기록은 최근 3년 폐업률에서도 폐업으로 세지 않고(`:109`, 종료일 비교), 평균 업력에서는 빠진다(`:104-105`, `nanmean`). 휴업 업소를 영업 중으로 보는 것도 같은 방향(생존 쪽)으로 작용할 수 있다. 화면에는 생존율 항목만 짧게 적었다.
- censoring: 관측기준일(`종료일` 최댓값, `:89`)에서 N년이 지난 인허가만 분모 (`:77-78`). 코호트 창 2013-01-01 이후는 생존율에만 적용하고 업력·폐업률은 전체 기록으로 계산 (`:38-42` 주석).
- 음식 업종: `build_food`가 상호 키워드(`NAME_RULES`) → 업태구분명(`UPTAE_RULES`) 순으로 업종을 매핑하고 같은 `ES.build`로 계산 (`etl_stability_food.py:28-50` 규칙, `:69-78` `classify`, `:81-91` `build_food`). 빵/도넛은 과자점 업태 + 제과 상호로 근사(모듈 주석 `:19`).

## 5. 검토가 필요한 주장 (팀 확인 요청)

1. 실태조사·연구 인용(근거조사 1장)의 원문 재확인 — 확인되면 출처와 함께 수치를 넣을 수 있다.
2. 고객성 도입 근거 문헌 — 원본도 "직접 근거 약함"으로 적었다.
3. 안정성 런타임 CSV의 생성 이력 — ETL 규칙은 원본 코드(`etl_stability.py`, `etl_stability_food.py`)로 확인했지만, 런타임 CSV가 그 코드·현재 입력으로 만들어졌는지는 확인하지 못했다(2-1 (c)). 필요하면 원본 ETL을 scratch 사본으로 재실행해 출력 동일성을 확인한다.
4. "안정성에 비교적 큰 비중" — 원본은 "일반 상권분석보다 높게"라고 적었지만 비교 대상 서비스의 가중치는 확인하지 못해 비교 표현은 넣지 않았다.
5. 서울시 상권분석서비스와의 지표 대응(근거조사 2장)은 화면에 넣지 않았다. 소진공 부분이 2차 자료에만 근거하기 때문이다.
