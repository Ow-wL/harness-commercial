## 4번 먼저: 집적 효과가 점수에 반영되어 있는가

### 확인 결과 — 부분적으로만 반영, 주력 지표는 반대 방향

| 관점 | 번화가에 들어갈 때 | 이유 |
|---|---|---|
| 경쟁성 P2 점포당 잠재수요(가중 0.5) | **불리** | 잠재수요에 반경 내 **거주인구만** 들어감. 번화가는 사는 사람보다 오는 사람이 많은데 그게 빠짐 |
| 경쟁성 P1 동종업종 비중(가중 0.3) | 일부 유리 | 다른 업종 점포가 많으면 비중이 낮아져 점수가 오름 |
| 시장성 유입인구 | 구분 못 함 | 생활이동 데이터가 구 단위라 같은 구 안의 번화가와 주택가가 같은 값 |
| 입지성 | 일부 유리 | 번화가는 대개 역·유인시설 근처 |

**데이터로 확인한 것 (인천 158개 동 중심점, 반경 500m)**

반경 내 전체 점포 수로 동네를 줄 세워, 상위 20%(번화가)와 하위 20%(한산한 곳)의 점포당 잠재수요 백분위 평균을 비교했다.

| 업종 | 번화가 상위 20% | 한산 하위 20% | 점포 수와의 순위상관 |
|---|---|---|---|
| PC방 | 40.7 | 63.5 | −0.37 |
| 생맥주 전문 | 34.4 | 55.3 | −0.32 |
| 미용실 | 40.1 | 60.6 | −0.29 |
| 치킨 | 47.8 | 51.4 | −0.10 |
| 카페 | 37.4 | 36.2 | −0.10 |
| 백반/한정식 | 35.1 | 39.1 | −0.11 |
| 편의점 | 40.7 | 41.4 | −0.04 |

- PC방·생맥주·미용실은 번화가일수록 경쟁성 주력 지표가 뚜렷하게 낮다. 교수님 지적이 맞다.
- 종사자(직장인)를 잠재수요에 더해 봐도 거의 바뀌지 않았다(PC방 번화가 40.7 → 42.0). 직장인도 행정동 값을 나눠 넣는 방식이라 번화가 방문객을 못 잡는다.
- 설계서에는 "잠재수요 = 유입인구 × 0.3 + 거주인구 × 0.7"로 집적 효과를 고려한다고 적었지만, 인천은 동 단위 유입인구가 없어 실제 반경 계산에는 거주인구만 들어가고 있었다. **문서·PPT의 공식 설명을 실제 계산에 맞게 정정했다**(점수산출 상세설명, 설계서, 발표구성안, 발표 PPT 8장).

### 개선 방향 3가지

**A. 방문 인구를 잠재수요에 넣기 (근본 해결, 1번 데이터 필요)**
- 잠재수요 = 거주인구 + 방문(유동)인구 × 계수
- 지오비전 퍼즐의 '서비스 인구'(거주·직장·방문 인구) 또는 '유동인구'를 반경 500m 단위로 받으면 된다.

**B. 업종별로 집적 효과를 다르게 보기 (지금 데이터로 바로 가능)**
- 소매입지 이론의 '누적 유인 원리'(Nelson, 1958): 비교해서 고르는 업종은 모여 있을수록 손님이 더 온다.
- **집적형 업종**(음식점·카페·주점 등 고르러 가는 업종): '상권 집적도'(반경 내 전체 점포 수 백분위)를 플러스 지표로 추가
- **근린형 업종**(편의점·세탁소·미용실·약국 등 가까운 곳을 쓰는 업종): 지금처럼 경쟁 부담으로 계산
- 어느 업종이 집적형인지는 C로 데이터 검증 후 확정

**C. 다른 상권분석 데이터로 검증 (2번 피드백)**
- 서울시 상권분석서비스 공개 데이터(상권별 점포 수·추정매출)로 "점포가 많은 상권일수록 점포당 매출이 높은가"를 업종별로 확인
- 매출이 같이 오르는 업종 = 집적형, 떨어지는 업종 = 근린형으로 분류 → B에 반영
- 인천에는 매출 원본이 없어서, 매출이 공개된 서울 데이터로 '규칙'을 검증하고 그 규칙을 인천에 적용하는 방식

## 1번: 지오비전 퍼즐 (SK텔레콤)

- 서비스: https://puzzle.geovision.co.kr/
- 유동인구 데이터 설명: https://puzzle.geovision.co.kr/data/%EC%9C%A0%EB%8F%99%EC%9D%B8%EA%B5%AC-d1653289902820
- 자주 묻는 질문: https://puzzle.geovision.co.kr/faq
- API 신청: SK open API https://openapi.sk.com/

| 항목 | 내용 |
|---|---|
| 데이터 | 휴대폰 기지국 신호 기반 유동인구 |
| 공간 단위 | 50m 단위 pCell(위치 오차 수십 m) |
| 구분 | 시간대 · 성별 · 연령대 |
| 범위 | 전국 250개 시군구 (인천 포함) |
| API 종류 | 유동인구 API, 서비스 인구 API(거주·직장·방문 인구, 시간별), 출발-도착 통행 API |
| 요금 | SK open API 무료 요금제 있음, **대학(원)생도 이용 가능**. 무료 제공량 수치는 미공개 → data-puzzle@sk.com 문의 |

**우리에게 주는 것**
- 경쟁성: 반경 500m 방문 인구로 번화가 불리 문제 해결(A안)
- 시장성: 지금은 구 단위(부평구 전체가 같은 값) → 지점·동 단위로 해상도 향상
- 시간대 적합도: 구 단위 시간대 분포 → 지점 주변 시간대 분포

**다음 할 일**
1. SK open API 가입 → 무료 상품에서 퍼즐 API 신청
2. 무료 호출 한도 확인. 비교 기준(인천 158개 동)을 만들려면 최소 158회 + 분석 지점 1회 필요(유동인구는 업종과 무관하므로 업종마다 다시 부를 필요 없음)
3. 부평역 반경으로 시험 호출 → 응답 형식 확인 후 엔진 연결
