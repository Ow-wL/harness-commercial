## 실행
Python 3.10 이상, `pip install pandas numpy scipy openpyxl`

```bash
cd 04_엔진코드
python3 run_all.py        # 05_분석결과 에 순위표·JSON 재생성 (1~2분)
python3 sensitivity.py    # 가중치 민감도 재계산
cd engine && python3 test_weights.py && python3 test_access.py
```
이 폴더 그대로 새로 돌려서 순위표가 같게 나오는 것을 확인했다.

안정성 패널을 원본부터 다시 만들려면 (결과가 07_가공데이터의 패널과 같게 나오는 것을 확인했다):

## 화면 연결 (3번 담당용)
엔진 호출: `scoring.analyze(site, dong, panel, ..., user_weights=None, importance=None, user_licenses=None, schools=None)`

결과 JSON 주요 항목 (`05_분석결과/업종별_상세JSON/full_PC방.json` 참고):
- `종합.점수`, `종합.병목_지표`, `종합.적용_가중치`
- `지표[]` — 5개 관점별 `score`, `confidence`, `breakdown`(세부지표별 점수·기여도·원시값)
- `경고[]` — 병목, 진입장벽, 학교 주변 규제 등
- `초보자_접근성` — 제도 진입장벽(낮음/중간/높음)과 이유. **점수에는 반영되지 않는다**

사용자 조건 넣는 법:
- 중요도 슬라이더 1~5 → `importance={"stability": 5, "competition": 4}` (생략한 관점은 3)
- 가중치 직접 입력 → `user_weights={"market": 0.3, ...}` (합이 1이 아니어도 정규화)
- 보유 면허 → `user_licenses=["미용사(일반)"]`

## 현재 한계 (발표 때 밝힐 것)
- 안정성은 13개 업종(PC방 + 음식 12개)만 계산된다. 미용·세탁·노래방 등은 인허가 파일을 받으면 채워지고, 편의점·슈퍼·요가(자유업)와 학원·독서실(교육청 소관)은 공공 인허가 데이터가 없다.
- 시장성·안정성은 구 단위, 임대료는 인천 9개 상권 단위다.
- 가중치는 실증되지 않았다(민감도 분석으로 결과가 가중치에 크게 흔들리지 않음을 보였다).
- 분석 지점은 부평역 하나다.
- 점수는 인천 내 상대 순위이며 매출을 뜻하지 않는다.
