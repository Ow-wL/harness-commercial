## 1. 타겟 재정의: 청년 예비창업자 — 유지

v1 그대로 유지한다. 근거 데이터도 유효하다.

- 청년 취업난 지속, 창업 전환 (2025.7 기준 20~29세 고용 약 45.8%, 15개월 연속 감소)
- 2025년 1분기 30세 미만 청년 사업자 수 전년 대비 6.9%(약 6천 명) 감소, 소매·음식업 타격
- 폐업 소상공인 중 **1~3년차 단기 폐업 34.3%**, 1년 미만 5.6%
- 창업 주저 이유: 자금 조달(18.2%)과 함께 **창업 정보·경험 부족(10.2%)**

**추가 근거 (v2):** 중기부가 국세청 자료를 분석해 발표한 **인천 폐업률 9.73%**. 광역 단위지만 인천이 특별히 안전한 지역이 아니라는 공식 수치다.

> **설계 반영:** 이 "1~3년차 34.3%" 숫자 때문에 스코어링에서 **안정성 가중치를 일반 상권분석보다 높게(0.18~0.22)** 잡았다. 기존 서비스가 "얼마 벌까"를 보여준다면 우리는 "버틸 수 있나"를 같이 본다. 제품 철학을 숫자로 박은 것이다.

## 2. AI 분석 범위 — Lv.2/Lv.3 충돌 해소

v1은 "MVP는 Lv.2까지, Lv.3은 책임 소재 이슈로 향후 과제"라 했는데, PPT 슬라이드 4·9는 "행동 제안 3가지"를 MVP에 넣었다. **둘 다 맞게 정리한다.**

| 레벨 | 내용 | MVP 포함 |
|---|---|---|
| Lv.1 | 데이터 요약 (현황 시각화) | ✅ |
| Lv.2 | 인사이트 도출 | ✅ |
| Lv.2.5 | **조건부 정보 제시** ← 신설 | ✅ |
| Lv.3 | 구체적 액션 단정 | ❌ 향후 |

**핵심 규칙: 판단 동사를 쓰지 않고, 비교 가능한 수치를 나란히 놓는다.**

| ❌ Lv.3 (단정) | ✅ Lv.2.5 (조건부 정보) |
|---|---|
| "부평2동으로 옮기세요" | "임대료가 ㎡당 30,775원으로 인천 상위권입니다. 인접 부평2동은 22,400원입니다." |
| "PC방은 하지 마세요" | "이 동네 PC방 3년 생존율 48%는 인천 평균 55.2%보다 낮습니다. 최근 1년 2곳이 순증했습니다." |

결정은 사용자가 한다. 책임 소재를 피하면서 실질적으로는 더 유용하다. PPT의 "행동 제안 3가지"는 이 형태로 출력하면 v1 원칙과 충돌하지 않는다.

## 3. 지역 범위: 인천 확정 ✅

v1은 "서울열린데이터광장은 서울 전용이라 인천 전환 시 데이터 공백. 커버리지 확인 후 최종 결정"으로 미확정이었다. **조사 결과 인천으로 확정한다.**

### 5대 관점 구현 가능성

| 관점 | 인천 가능 여부 | 주 데이터 |
|---|---|---|
| 경쟁성 | ✅ | 소진공 상가정보 (점포 좌표 + 업종 247개 소분류) |
| 고객성 | ✅ | 행정동 성별·연령별 주민등록인구 (월간) |
| 입지성 | ✅ | 인천교통공사 역사정보 + 학교 표준데이터 |
| 안정성 | ✅ | 행안부 인허가 (인허가일자+폐업일자) |
| 시장성 | ⚠️ 조건부 | **수도권 생활이동** (아래) |

### 유동인구는 있다 — 단, 시군구 단위

v1의 "서울 데이터라 인천은 안 된다"는 가정이 **한 데이터셋에는 틀렸다.**

**수도권 생활이동** (서울시 × KT)은 공식 문구상 *"행정동, 자치구 단위는 수도권(서울, 경기, 인천) 지역만 나오고 나머지 지역은 시·도 단위로 나옵니다."*

- 인천 **행정동 단위** 포함
- 성·연령별 × **일별·시간대별** × **이동목적 7종**(출근/등교/쇼핑/관광/병원/귀가/기타)
- 2023-01 ~ 2026-08, 월 1회 갱신
- 공공누리 1유형 → 상업 이용 가능

**이동목적 분해가 된다는 게 결정적이다.** "쇼핑 목적 유입"은 단순 유동인구보다 시장성의 직접 지표다. 그리고 시간대별이 나오므로 **업종 영업시간과의 적합도**를 계산할 수 있다 — 유동인구 총량이 같아도 카페와 호프집은 전혀 다른 결론이 나온다. **총량만 보는 기존 서비스가 못 하는 계산이다.**

### 여전히 없는 것 — 매출

인천에는 행정동 단위 매출/소비 원본이 **없다.** 서울(골목상권)·경기(GMR)에 대응하는 광역 상권분석 인프라 자체가 인천엔 없다.

| | 서울 | 경기 | 인천 |
|---|---|---|---|
| 광역 상권분석 서비스 | golmok.seoul.go.kr | sbiz.gmr.or.kr | **없음** |
| 행정동 추정매출 | ✅ | △ | **없음** |

**⚠️ 쇼핑·관광 목적은 인천에서 사용 불가** — 11개 구 중 쇼핑>0이 2개(연수·미추홀), 관광>0이 1개(제물포)뿐. 대체 지표로 **직장성**(출근유입/(출근+귀가))을 쓴다. 인천 0.194(검단구, 베드타운) ~ 0.365(제물포구, 개항장·오피스)로 변별력이 확인됐다.

**→ 대응 원칙 (기획서 명문화):**
1. **절대 매출액을 추정하지 않는다.** 원본이 없으므로 절대값 주장은 근거가 없다. **인천 내 상대 순위(백분위)**로만 말한다
2. 모든 지표에 **출처와 기준시점을 UI에 명시**한다 (공공누리 1유형 출처표시 조건이기도 함)
3. 프록시 지표: 인천e음 결제금액(군구), 지하철 승하차, 점포 밀도

> **이건 약점이자 진입장벽이다.** 인천은 전국 데이터로 직접 계산해내야 하는 지역이고, 그래서 아무도 안 만들었다. 우리가 만들면 대체재가 없다.

### ⚠️ 인천 행정구역 개편 — 2026-07-01 시행 완료

v1 작성 시점엔 없던 변수다. **31년 만의 개편이 이미 시행되었다.**

| 이전 | 이후 |
|---|---|
| 중구(내륙) + 동구 | **제물포구** |
| 중구(영종도) | **영종구** |
| 서구 | **서해구**(명칭 변경) + **검단구**(분리) |

최종 **2군 9구**: 강화군, 옹진군 / 제물포구, 영종구, 미추홀구, 연수구, 남동구, 부평구, 계양구, **서해구**, 검단구

> **서구 → 서해구 명칭 변경**에 주의. 38년 만의 개명이며, 소진공 상가정보 2026-06-30 기준 데이터에 이미 '서해구'로 반영되어 있다(서구 레코드 0건). 실데이터로 확인함.

**설계 영향:**
- **소진공 상가정보(2026-06-30)는 이미 신 행정구역으로 갱신되어 있다** — 실데이터 확인. 다른 데이터셋도 개별 확인 필요
- **행정동 코드를 단일 기본 키로 고정하고, 시군구는 파생 속성으로 처리한다.** 시군구를 조인 키로 쓰면 데이터가 깨진다
- MVP 샘플은 **부평역**이므로 영향 없다(부평구는 개편 대상 아님). 확장 시점에 다룬다

## 4. 핵심 플로우: 역질문 방식 — 유지

v1 그대로. 기존 서비스와의 차별점이 여기다.

| 기존 방식 | 우리 방식 |
|---|---|
| 지역 선택 → 분석 결과 열람 (수동적) | 업종 입력 → **"이 지역에서 이 업종 괜찮은가?"** 적합도 진단 (능동적) |

**v2 추가 — 가중치 공개 슬라이더:**

스코어링 가중치는 현재 도메인 상식 기반 추정이고 실증되지 않았다. 검증하려면 "성공 점포 vs 폐업 점포" 사후 데이터가 필요한데 MVP 기간엔 불가능하다.

→ **가중치를 UI에 공개하고 사용자가 조절하게 한다.** "당신에게 중요한 건 뭔가요?"는 역질문 컨셉과 맞고, 조절 로그가 쌓이면 **PPT의 '데이터 축적 후 ML 도입' 계획에 실제 학습 데이터가 생긴다.** 약점을 로드맵으로 전환하는 설계다.

## 5. 정부지원사업 매칭 — 🔴 중대 정정

### v1의 오류

v1은 이렇게 적었다:

> *"사업요건 또한 연령·창업연차 기준이 제각각임 (예: 예비창업패키지는 만 29세 이하 생애최초 창업자, 일반 청년창업지원은 만 39세 이하 창업 3년 이내 대표자)"*

**예비창업패키지 부분이 사실과 다르다.**

### 2026년 실제 조건 (중기부 공고 제2026-207호 / 수정공고 제2026-143호)

| 항목 | v1 서술 | 실제 |
|---|---|---|
| 연령 | 만 29세 이하 | **제한 없음** (전 연령 신청 가능) |
| 생애최초 | 필수 조건 | **조건 없음** |
| 업력 | 미기재 | 신청자 명의 사업자등록증 미보유 (기준일 2026.1.22.) |

"만 39세 이하"는 **제외 조건**에만 등장한다 — *「'19년 이후 예비창업패키지 수혜 이력이 있는 자로서 '최우수' 성과평가를 받고 공고일 기준 만 39세 이하인 자는 제외」*

신청기간 2026.03.06~03.24 / 사업화 자금 평균 0.4억원 / 특화분야 여성 70명·소셜벤처 70명·사내벤처 50팀

### 확인된 다른 사업 (대체 예시로 사용)

| 사업 | 연령 | 업력 |
|---|---|---|
| 청년창업사관학교 (창업성공패키지) | 만 39세 이하 | 창업 3년 이내 (경험창업자 7년) |
| 청년전용창업자금 (중진공) | 만 39세 이하 | 사업개시 3년 미만 (예비창업자 포함) |

### 🔥 이 오류를 발표 자산으로 쓸 것

v1의 주장은 *"기준이 세분화되어 있어 본인 해당 여부 파악 자체가 진입장벽이 되고, 정보는 존재하나 '나에게 맞는 것을 찾아 신청까지 연결'되는 과정에서 누수가 발생함"* 이었다.

**이 오류가 그 주장을 그대로 증명한다.** 프로젝트를 기획한 사람조차 대표적인 지원사업의 연령 조건을 틀렸다. 자료를 찾아보고 쓴 문장인데도 틀렸다.

> **발표 구성 제안:** "저희도 기획 단계에서 예비창업패키지 연령 조건을 잘못 알고 있었습니다. 공고문 원문을 확인하고서야 알았습니다. 이게 바로 저희가 풀려는 문제입니다."
>
> 문제를 추상적으로 설명하는 것보다 훨씬 강하다. 오류를 숨기지 말고 증거로 쓸 것.

### 구현 — API 조합 확정

| API | 역할 |
|---|---|
| **K-Startup** `getAnnouncementInformation01` | **매칭 정확도.** 연령(`biz_trgt_age`)·업력(`biz_enyy`)·지역(`supt_regin`)·분야(`supt_biz_clsfc`)를 **구조화 필드로 동시 제공하는 유일한 API.** `biz_enyy`에 "예비창업자" 값 존재 |
| **기업마당** `bizinfoApi` | **커버리지.** `searchLclasId=06`(창업) + `hashtags=인천`으로 지자체·유관기관 공고 보완 |

- K-Startup은 **LLM 본문 파싱 없이 결정론적 필터링**이 가능하다 → v1의 면책 원칙과 잘 맞는다
- ⚠️ `supt_regin` 서버측 필터가 불안정하다는 보고 → 전량 수집 후 클라이언트 필터링
- 두 API 중복 제거 로직 필수
- 인천시·인천테크노파크는 **공고 API가 없다**(정적 HTML/PDF). 기업마당으로 상당 부분 커버되고, 부족분은 별도 크롤러 과제

### 면책 원칙 — 유지·강화

AI는 **확정적 지원 가능 여부를 판단하지 않는다.** 반드시 원문 공고 확인을 안내한다. 위 v1 오류 사례가 이 원칙이 왜 필요한지를 증명한다.

## 6. 종합 결론 — 유지, 근거 보강

v1의 핵심 명제는 그대로 유효하다.

> "정보 부족"이라는 하나의 문제가 ① 상권/입지 정보 부족 ② 정부지원 정보 부족이라는 두 갈래로 나타난다. 기존 서비스는 이 중 하나만 다루거나 서로 연결되지 않는다. 본 프로젝트는 AI 매니저가 사용자 프로필을 기반으로 두 문제를 동시에 해결하는 것을 핵심 차별화 포인트로 삼는다.

**v2 보강:** 조사 결과 이 명제가 인천에서 더 강해졌다.

1. **인천에는 상권분석 서비스 자체가 없다.** 서울 골목상권·경기 GMR에 대응하는 게 없어서, 인천 예비창업자는 ①번 정보를 얻을 곳이 사실상 없다
2. **②번은 기획자도 틀렸다.** 정보가 존재해도 도달하지 못한다는 증거
3. 두 문제를 잇는 연결고리(사용자 프로필 재사용)는 **K-Startup API의 구조화 필드로 기술적으로 확인**되었다

### 안정성 — 인허가 데이터로 계산한 실측 생존율

**계산상 주의 2가지**
- **Censoring** — 2024년 인허가 업소는 아직 3년이 안 지났다. 분모에 넣으면 '아직 안 망했다'가 '3년 생존'으로 잘못 집계된다. → N년이 경과한 코호트만 분모로 쓴다
- **종료 판정** — '폐업'(2,672건)뿐 아니라 '취소/말소/만료/정지/중지'(1,017건)도 실질적 종료다. 둘을 합쳐야 실태에 맞다

**해상도는 시군구** — 인허가 4,701건을 158개 행정동 × 연도별 코호트로 쪼개면 칸당 1~2건이라 생존율이 무의미해진다. `fallback: "gugu_sobun"`으로 기록해 LLM과 사용자에게 노출한다.

**🔴 입지성 데이터의 한계 — 승하차를 쓸 수 없다**

코레일 '역별 승하차' 공공데이터는 **KTX·ITX 등 일반철도 전용**이고 수도권 광역전철이 빠져 있다. 인천교통공사 데이터에는 인천1·2호선과 7호선만 있다.

그 결과 **부평역이 인천1호선 분(일평균 14,090명)만 집계되어 71개역 중 26위**로 나온다. 부평시장역(24,912명)보다 낮다. 인천 최대 환승 거점인데 말이 안 되는 수치다.

→ 승하차를 점수 산출에서 **제외**하고, **환승 가중 역세권 강도**로 대체했다.
```
역세권 강도 = Σ (1 + 환승노선수) × exp(-거리 / 400m)
```
부평역은 경인선 + 인천1호선 환승이라 가중치 4.0. 광역전철 승하차가 개방되면 교체할 것.

**⚠️ 역 병합 주의** — 같은 물리적 역이 노선별로 따로 등록된다. `부평역`(경인선, 37.4895)과 `부평`(인천1호선, 37.4905)은 **120m 떨어진 같은 역**이다. 좌표 격자로만 묶으면 경계에서 갈라지므로, 역명 정규화 후 400m 이내를 병합한다.

**⚠️ 유인시설은 학교 데이터만으로 부족** — 표준데이터에는 초·중·고만 있고 학원·대학이 없다. PC방의 유인시설 기준이 "중학교, 고등학교, 학원, 대학교"인데 학원이 매칭되지 않아 부평역 반경 500m 해당시설이 **0개**로 나왔다. → 상가정보의 학원(P10501)·독서실(R10202)을 유인시설에 합쳐 **4,792개**로 늘리자 **19개**로 정상화됐다.

### 🔴 그 과정에서 드러난 결함 — 유인시설 스케일 불균형

유인시설 개수가 종류마다 **100배 가까이 차이난다**(오피스 12,162 vs 고등학교 129). 근접도를 `Σ exp(-d/300m)` 으로 한 번에 합치면 개수가 많은 종류가 합계를 지배해서, **`ANCHOR`에 '오피스'가 들어간 업종이 전부 95.7로 붙어버렸다**(세탁소·요가·미용실·유흥주점·일식…).

→ **종류별로 백분위를 낸 뒤 평균**하도록 고쳤다. 그래야 '고등학교 129개'와 '오피스 12,162개'가 동등한 무게를 갖는다. 입지성 고유값이 3 → 13으로 벌어졌다.
